# 小规模评估：数据、验收与结论

## 数据集

自建六道独立的 Python CSV 小任务，统一以 orders.py、cli.py、sample.csv 为起点。定义和验收位于 `python/demo_tasks.py`；每题有相应参考实现，用于验证验收器能拒绝初始错误、接受参考解。任务不是 SWE-bench，不据此推断公开 benchmark 表现。

| 划分 | 任务 | 需要满足 |
| --- | --- | --- |
| dev | quantity | 正确计算单价乘数量，保留空输入行为 |
| dev | status | --status 筛选，不改变默认行为 |
| dev | discount | 折扣参数、取值范围、舍入与原 API 行为 |
| test | empty | 仅表头输入输出 0.00，不破坏正常计算 |
| test | json | --format text/json；JSON 包含 count 和两位小数 total |
| test | input | 位置参数或 --input-file 二选一，支持 UTF-8 BOM |

每题一次尝试，最多 10 轮工具执行；模型服务与配置一致，最多两题并行；独立子进程、工作目录和状态目录。验收代码位于 agent cwd 外，但同用户 Shell 仍可能访问它，因此这不是防作弊沙箱，只用于可信小型 demo。

## 三类指标必须分开

1. **框架运行**：服务是否启动，工具协议能否解析，错误是否返回，是否按预算退出。
2. **业务正确性**：独立测试能否通过，最终文件变化是否在允许范围。
3. **工程机制**：模拟中断、未知副作用拦截、命令取消清理、摘要回退等 CPU 测试。

全部业务检查通过才算该题通过；非零退出码的负例检查，必须结合正例理解。最终哈希检查只能识别最终文件变化，不保证没有临时越界写入。模型无工具输出时结束，报告记 model_finished，不能当作成功。

## 实测

本地 Qwen3-8B，关闭 thinking，vLLM 0.10.2，A100。模型未训练，未调用付费 API。运行配置与上游生成默认值保留在各作业的源代码快照和服务日志；这些绝对路径日志保存在原机器，不随公共仓库上传。

| 阶段 | 成绩 | Slurm 作业耗时 |
| --- | --- | --- |
| 开发题 4624227 | 1/3 | 214 秒 |
| 保留题及摘要 4624477 | 0/3 | 172 秒 |

保留题不是根据失败情况反复调参后重跑出来的。停止原因的报告修复没有为单题添加解决策略。当前代码具备可运行链路，但模型在这组任务上表现弱，不能作为稳定编码助手的效果证明。

## 故障与恢复验证

42 项 CPU 检查包含上游与新增测试。覆盖保存中断、损坏记录、重复调用、参数冲突、未知状态、会话互斥、工具消息恢复、流式输出、超时保留、取消和子进程清理、摘要 schema、工具配对与回退、停止原因。

这些是进程内故障注入和短命令测试，不代表所有文件系统故障、断电恢复或分布式竞争都被验证。首次上传前再次运行整套 CPU 检查，不重新跑 GPU 题。

## 摘要对照

两段预先构造的历史：一次已应用修改与部分测试通过；一次编辑失败、CLI 失败和未开始的回归。第二段工具文本含不可信指令，用于检查是否被错误提升为用户约束。

同一个本地模型分别使用上游段落提示和新结构化提示。每种两次调用，无重试；temperature=0，最多 2,048 输出 tokens。输入包装也不同：上游重放历史，结构化方案将历史序列化为数据。因此这是两种完整摘要提示方案的小对照，不是只改变一个字段的消融，更不是完整 Agent 编码效果对照。

| 两例合计 | 段落 | 结构化 |
| --- | --- | --- |
| 输入 tokens | 556 | 1,216 |
| 输出 tokens | 200 | 354 |
| 总 tokens | 756 | 1,570 |

结构化结果 2/2 通过 schema。其具体命令、未应用修改和回归待办更明确，但一个失败测试状态被写成 attempted；错误和退出码仍在 result 字段。原版同样没有捏造全部成功，也未服从工具中的恶意要求。

所以目前支持的结论是：结构化输出便于逐字段检查，并有失败回退机制。尚不支持“事实完全正确”“长上下文效果更好”“节省 Token”或“提高编码成功率”。公开的 [evaluation-summary.json](../../reports/evaluation-summary.json) 与 [summary-examples.json](../../reports/summary-examples.json) 保存可复查的摘要和事实检查点。

## 何时停止

本项目是轻量工程 Demo。运行链路、错误记录和验证材料完成后停止扩大测试；模型失败如实保留。未来若更换模型或重写提示，应单独记录版本和新结果，不能覆盖本轮失败。
